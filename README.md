# 통합 봇: 음악 + 카지노 게임 (하나의 토큰)

discord.js v14 기반. **하나의 봇**에 음악 재생(Lavalink)과 게임(슬롯/과일팡/블랙잭/하이로우)이 함께 들어 있습니다.

## 구조
- 클라이언트·이벤트·명령어 등록은 `index.js` **하나**가 총괄
- 음악: `music-channel.js`, `charts-source.js`, `utils.js`, `commands/`, `lavalink/`
- 게임: `casino.js`(라우터) + `slot.js` `cascade.js` `blackjack.js` `highlow.js` `cards.js` `economy.js`
- 저장: `data/` 폴더 (음악 채널 설정 + 코인 잔액 JSON)

## 설치
```bash
cd music-casino-bot
npm install
copy .env.example .env   # mac/linux: cp
```
`.env` 에 `DISCORD_TOKEN`, `CLIENT_ID` 입력. (음악용 `LAVALINK_*` 는 기본값 그대로 두면 됩니다.)

### 음악 기능을 쓰려면 (게임만 쓸 거면 생략 가능)
1. `lavalink/` 폴더에 `Lavalink.jar` (v4) 다운로드해 넣기
2. `cd lavalink && java -jar Lavalink.jar` 로 별도 실행 (창 유지)

### 봇 실행
```bash
npm start
```
시작 시 **모든 명령어(음악+게임)가 들어가 있는 모든 서버에 자동 등록**됩니다. 새 서버 초대 시에도 즉시 등록돼요.

> 인텐트: 디스코드 개발자 포털 → Bot → **MESSAGE CONTENT INTENT 켜기** (음악 채널 입력 기능에 필요). 게임만 쓸 거면 없어도 동작은 하지만, 켜두는 걸 권장합니다.

## 명령어
### 🎵 음악
`/셋업` (관리자, 음악 채널 지정) · `/재생` `/스킵` `/일시정지` `/다시재생` `/정지` `/큐` `/재생정보` `/볼륨` `/반복` `/이동` (구간 점프, 예: `1:30`)
- `/셋업` 한 채널에서는 노래 제목/링크를 입력하면 바로 재생, 고정 플레이어 패널이 실시간 갱신, 📈 인기차트(자동 갱신)

### 🎰 게임 (가짜 코인)
`/슬롯` · `/과일팡` · `/블랙잭` · `/하이로우` · `/룰렛` · `/크래시` · `/경마` · `/노가다` · `/잔액` · `/출석` · `/파산` · `/랭킹` · `/도움`
- 결과 화면 상단에 **플레이어 이름 + 아바타**가 크게 표시됩니다
- `/룰렛`: **유러피언 룰렛 GIF** — 휠이 돌다 감속해 멈추는 연출 (빨강/검정/홀짝 x2, 숫자 x36, RTP ~97%)
- `/과일팡`: **움직이는 GIF 연출** — 과일 심볼(체리·딸기·포도·레몬·수박·별)이 위에서 쏟아져 채워지고(텀블 낙하), 매칭되면 펑펑 터짐. 연쇄 도중 🎆 스캐터가 섞여 떨어지며 착지 시 강조
- 🎆 스캐터 3개=프리스핀 5회 · 4개=7회 · 5개+=10회 → **붉은/금색 보너스 GIF**(은은한 반짝이)로 자동 진행
- `/슬롯`: **릴 GIF** — 3릴이 돌다 왼쪽부터 하나씩 멈춤, 잭팟 번쩍. `/블랙잭`·`/하이로우`: **카드 테이블 이미지**로 표시
- 모든 GIF는 1회 재생 후 **마지막 장면 사진으로 자동 교체**됩니다 (다시 봐도 재생 안 됨)
- 환수율: 슬롯 86~88%, 과일팡 ~92%(보너스 포함), 블랙잭 94%, 하이로우 92%
- 시작 1000코인, `/출석` 매일 +500, `/파산` 구제 +300
- `/크래시`: 배율이 실시간으로 오르는 동안 💰캐시아웃 버튼 타이밍 게임 (RTP ~96%)
- `/주사위대결 [상대] [판돈]`: 유저끼리 2d6 코인 대결 (수락/거절 버튼, 주사위 GIF)
- `/송금 [받는사람] [금액]`: 유저 간 코인 송금
- `/경마 [말 1~6] [베팅]`: 채널 모두가 25초간 함께 베팅 → 6마리 레이스 GIF, 적중 x5.5 🏇 (혼자도 가능)
- 💰 **잭팟 풀**: 모든 베팅의 1%가 쌓이고 `/슬롯` 777 잭팟 시 전액 지급 (`/잭팟`으로 확인)
- 🏆 `/랭킹`: 보유 코인(전체) + **이번 주 순익**(매주 자동 리셋) 동시 표시
- 🎵 `/플리 저장|재생|목록|삭제`: 현재 큐를 내 플레이리스트로 저장하고 언제든 불러오기
- 🛡️ 전역 에러 가드: 오류가 나도 봇이 죽지 않고 해당 명령만 실패 처리

### 🗼 등반 — 덱빌딩 카드 전투 (슬레이 더 스파이어풍)
- `/등반`: **캐릭터 3종**(⚔️전사=시작 블록·🗡️도적=드로우 6장·🔮마법사=에너지 +1) 중 선택 — 시작 덱과 보상 카드 풀이 달라 빌드가 갈립니다. 시작 덱 10장으로 10층 탑 도전. **에너지 3·드로우 5·블록·적 의도(다음 행동 표시)** — 의도를 읽고 막을지 때릴지 수싸움
- 카드 26종 + 메커니즘 시너지: 힘(공격 누적강화)·독·약화(×0.75)·취약(×1.5)·소멸(강력한 1회용)·드로우·가시
- 전투 승리 → **카드 3장 중 1장 선택**으로 덱 빌딩, 🔥모닥불에서 **회복 / 카드 강화(+) / 카드 제거** 선택, 엘리트·보스
- 🏺 **유물 10종**: 엘리트 처치 시 확정, 일반 전투 10% 드랍 — 숫돌(공격+1)·강철 심장·타오르는 불씨(힘+1)·독사 송곳니·에너지 코어·전투의 북·행운의 동전 등 런 전체에 걸린 패시브
- 💾 **런 영구 저장**: 봇을 재시작해도 등반 진행(층·덱·유물·전투 상태)이 유지됩니다
- 도트 전투 화면: 손패가 **아이콘 아트 카드**로 표시되고 번호 버튼으로 사용. **카드마다 다른 이펙트 GIF**(베기/화염/독/방패/번개...) + 히트스톱·넉백·흔들림 타격감, 적 턴도 GIF
- 사망 시 런 종료(로그라이크) — 모은 코인은 유지. 클리어 시 보너스 +300
- `/내덱`: 현재 덱 확인 / `/노가다`: 광산에서 곡괭이질 GIF로 광물 캐기 (5분 쿨, 잡초~💎다이아)


> ⚙️ `/과일팡`은 매 스핀마다 GIF를 그려 올립니다(`sharp` 사용). 생성에 보통 **수 초**가 걸려서 "🎰 굴리는 중..." 표시 후 GIF가 올라옵니다. `sharp`는 미리 빌드된 바이너리라 `npm install`만으로 설치됩니다(별도 빌드 도구 불필요).

## 안내
게임은 **재미용 가짜 코인**입니다. 현금 가치가 없으며 실제 금전 거래·도박과 무관합니다.

## 충돌 없는 이유
음악 명령(`재생`, `셋업` 등)과 게임 명령(`슬롯` 등)은 이름이 겹치지 않고, `index.js` 의 인터랙션 라우터가 명령/버튼을 종류별로 갈라 처리합니다. 음악 버튼은 `music_`/`q_`, 게임 버튼은 `slot_`/`cas_`/`bj_`/`hl_` 접두사로 구분됩니다.
